# Musik Latar

Taruh file lagu di folder ini dengan nama **`song.mp3`**:

```
public/music/song.mp3
```

Selama file belum ada, tombol musik otomatis disembunyikan dan website tetap
berjalan normal — jadi tidak error.

Mau pakai nama file lain? Ubah `music.src` di `app/config.ts`.

Tips: kompres lagu ke ~128kbps supaya undangan cepat dibuka di HP.
